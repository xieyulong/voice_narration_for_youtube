# Stage Prompts

This project uses the simpler operating prompts in:

```text
docs/project_prompts.md
```

Use that file before starting work, before generating audio, and before pausing
or exiting the project.

For implementation work, keep the same core protocol:

1. Review the repo and required docs.
2. Present the plan and risks.
3. Wait for approval.
4. Implement only the approved scope.
5. Verify relevant checks.
6. Report modified files, tests, remaining issues, and recommended next steps.

Do not commit, push, tag, rewrite history, copy generated outputs, or modify the
old `voice_clone` repository unless the user explicitly asks.
